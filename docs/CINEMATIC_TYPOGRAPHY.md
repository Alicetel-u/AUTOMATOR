# Astra生成部品

ブラウザ版で選べるAstra生成部品は35種類です（前回の10種類を含む）。
レイアウト10、登場7、退場5、保持3、装飾3、文字加工1、背景2、カメラ2、つなぎ2。
別途、タイトル付き間奏を描く内部部品があります。

かんたんモードと「手法」タブにある **Astra生成部品を使う** で有効にします。
初期状態ではオフです。手法一覧では「Astra」印が付きます。

**Astraだけで生成する場合**は、演出のチェックを「Astra生成部品を使う」だけにします。
「基本の部品」「追加分」「和風」「文字PV系」「キネティック」「ホラー」はオフにしてください。
おまかせ・シャッフル・行の再抽選・タイトル・間奏・曲の終わりまで、Astra部品だけで構成します。
保存済みの行指定・ロックにある既存部品も、このモードではAstra部品に置き換えて表示します。
保存済み指定自体は書き換えないので、ほかの部品を有効に戻すと元の指定を使用できます。
配色・書体・画像・音声は共通です。「なし」は効果の不使用を表します。
部品単位のチェックを全部外したカテゴリでは、安全なAstra部品または「なし」に戻ります。

ほかの演出チェックもオンにすれば、Astraと既存部品を混ぜて生成できます。
前回の10種類は「文字PV系」からAstraへ移動しました。古いプロジェクトの基本部品は従来どおり有効です。

## 新しい字組み

| 名前 | 表現 |
| --- | --- |
| Astra・モニュメント | 太い文字と長いアクセント罫線 |
| Astra・二面の対話 | 句を二面に分け、縦画面では上下に配置 |
| Astra・縦組みの背骨 | 縦組みと細い側線 |
| Astra・額装タイポ | 余白を取った文字と細い額縁 |
| Astra・段差のリズム | 三段の字組みを階段状に配置 |
| Astra・水平線の詩 | 広い字間と水平線 |

## 前回の字組みと組み合わせ例

| 用途 | レイアウト | 登場 | 退場 |
| --- | --- | --- | --- |
| 映画のタイトル、静かな歌詞 | 余白のシネマタイトル | ピントが合う文字 | 活字の静かな閉幕 |
| 雑誌風の字組み | 余白のエディトリアル | 中央から開く活字 | 活字の静かな閉幕 |
| 奥行きと残像 | 奥行きの残像活字 | ピントが合う文字 | 水にほどける文字 |
| 絵を見せる余白 | ギャラリーの余韻 | 一字ずつ絹の浮上 | 水にほどける文字 |

静止中の「静かな浮遊活字」は、動きスライダーに応じて微小な上下移動と回転を加えます。
文字の読みやすさを重視する場合は、色ズレ・装飾・グリッチを控えめに設定してください。
画面比に応じて改行・文字サイズを調整します。配色と書体は選択中のスタイルを使います。
高速プレビューではピント演出のぼかしが省略される場合があります。

After Effectsへの書き出しでは、既存の近い演出への互換変換を使用します。
ブラウザ版と完全に同じ動きをAEネイティブで再現する追加実装は含みません。

実装: `src/11p_astra.js`、`src/11p_typo4.js`。専用モード: `src/11r_astra_policy.js`。
検証: `python dev/astra_check.py` と `python dev/astra_check.py --ui`（WindowsのChrome）。
Chromeの場所は環境変数 `CHROME_PATH` で変更できます。
